Use your quote library in Cursor

Install the Quotify MCP server in Cursor and reach for a saved quote while you write in the editor, from a README to an essay in Markdown.

A lot of writing happens in an editor: documentation, READMEs, talks, blog posts and essays kept in Markdown. With Quotify added as an MCP server, Cursor's agent can search the quotes you saved and work them into the file you have open, with the author attached.

Where you connect it in Cursor

The fastest route is the Add to Cursor button in the live setup steps (choose the Cursor tab), which installs the server for you. You can also add Quotify to your global ~/.cursor/mcp.json, or to .cursor/mcp.json inside one project if you only want it there. Then turn Quotify on under Customize in Cursor's sidebar and follow the sign-in prompt.

The live page has the exact configuration to copy, so use it rather than a snippet from an older article.

Before you connect

Turn on iCloud sync in Quotify and let your library finish syncing. When Cursor opens the sign-in page, use the Apple account that library uses.

What to ask Cursor

  • “Find a quote I saved about simplicity and add it as the epigraph at the top of this README.”
  • “I'm writing a talk in talk.md. Pull two quotes from my library about craft and suggest where they fit in the outline.”
  • “Add a short comment above this retry loop with the quote I saved about patience, and credit the author.”
  • “Search my saved quotes for anything by Ursula K. Le Guin and list them here before you change any files.”
  • “Save the line I just wrote in essay.md to Quotify, with me as the author.”

Ask Cursor to show you the quote and author before it edits a file, so the lookup and the change stay separate. Saving a new quote is optional; check the text and author before you approve it.

What the connection can and can't do

Cursor can search and read your saved quotes and, if you allow it, save new ones. It can't edit or delete anything in your library, and nothing in your project is sent to Quotify unless you ask to save it as a quote. You can disconnect at any time from Your connections.

If Cursor can't find your library

Check that Quotify is turned on under Customize, that you finished the sign-in with the Apple account your library syncs to, and that iCloud sync is on in the app. Never paste an Apple password or a token into the chat or commit one to a project file; use the sign-in prompt.
